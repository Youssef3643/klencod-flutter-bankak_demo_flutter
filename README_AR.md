# Bankak Demo — محاكاة مصرفية تجريبية

هذا مشروع Flutter تجريبي محلي، لا يتصل ببنك الخرطوم أو أي بنك، ولا ينفذ تحويلات أو شحنات حقيقية. جميع الأرصدة والحسابات والعمليات وهمية ومحفوظة محلياً على الجهاز.

## ما يتضمنه
- تسجيل حساب تجريبي باسم ثلاثي وكلمة مرور.
- رقم حساب تجريبي من 7 أرقام يبدأ بـ 2.
- رصيد ابتدائي 5,000 جنيه سوداني.
- شحن تجريبي بحد أقصى 3,000,000 SDG في العملية.
- تحويل بين الحسابات التجريبية الموجودة على الجهاز نفسه فقط.
- خصم من المرسل وإضافة للمستلم وسجل معاملات.
- إيصالات تجريبية، سجل المعاملات، تفاصيل الحساب، وملخص تسجيل الخروج.
- حفظ محلي باستخدام SharedPreferences.
- مشاركة وطباعة بيانات الإيصال.

## فتح المشروع
المجلد يحتوي على ملفات Flutter الأساسية (`pubspec.yaml` و`lib/main.dart`). لتوليد ملفات منصة Android القياسية:
1. ثبّت Flutter SDK وAndroid SDK.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   flutter create . --platforms=android
   flutter pub get
   flutter run
   ```
4. افتح المجلد نفسه في Klencod IDE أو Android Studio.

## ملاحظات مهمة
- الواجهة تحاول مطابقة الصور المرسلة في التخطيط والألوان والأزرار، لكن المطابقة الحرفية تتأثر بأبعاد الشاشة والخطوط والأصول الرسومية الأصلية التي لم تُرفق كملفات منفصلة.
- شعار التطبيق مرسوم كنص داخل Flutter وليس الشعار الأصلي.
- الحسابات تحفظ محلياً على الجهاز نفسه؛ لا يوجد خادم أو مزامنة بين الأجهزة.
- هذا نموذج أولي وليس تطبيقاً مصرفياً صالحاً للاستخدام الحقيقي.
